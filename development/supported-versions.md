# Supported versions

How to change the supported versions of PostgreSQL, Node.js, Bun, and TypeScript.

## PostgreSQL

- Support only PostgreSQL versions maintained by the PostgreSQL project, and state the minimum in [architecture/postgresql.md](../architecture/postgresql.md).
- Test the minimum and the newest supported major versions in the matrix of `.github/workflows/test.yml`.

## Runtimes

- Declare the minimum versions of Node.js and Bun in `engines` of `package.json` and in the install section of [docs/getting-started.md](../docs/getting-started.md).
- Test the minimum major version of Node.js in the matrix of `.github/workflows/test.yml` through `mise.node<N>.toml` and its lock file, generated by `MISE_ENV=node<N> mise lock`: CI installs tools in locked mode.
- State the minimum version of TypeScript for consumers in the install section of [docs/getting-started.md](../docs/getting-started.md), and keep it in `devDependencies` as `typescript-6`: the package test type-checks its consumer with it and with the pinned `typescript`.
